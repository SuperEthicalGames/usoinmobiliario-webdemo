# Uso Inmobiliario — Demo de rediseño

Demo estática de un rediseño profesional para [usoinmobiliario.com](https://www.usoinmobiliario.com), pensada como catálogo de apartamentos amoblados en Medellín (Laureles–Estadio).

Es un único archivo HTML autocontenido (sin build, sin dependencias de servidor) — todo el CSS, JavaScript e imágenes de las galerías 360° van embebidos en `index.html`. Los únicos recursos externos son Google Fonts y la librería three.js (CDN), usados para el visor 360° real de cada unidad.

## Contenido

- Catálogo con las 17 unidades reales (código, área, tarifas, disponibilidad).
- Ficha por unidad con recorrido 360° arrastrable (three.js) y tabla de tarifas real.
- Página de planes de renta corta.
- Sección legal con los documentos reales del sitio (reglamento, política de datos, contrato, código de conducta, etc.).
- Bilingüe (ES/EN).

## Estado

Fase de propuesta — fotografías 360° de banco de imágenes libres (no son fotos reales de las unidades). Pensado para mostrarle al dueño del negocio y proponer mejoras y precio de una implementación completa.

## Ver la demo

Abre `index.html` directamente en el navegador, o publícalo con GitHub Pages (Settings → Pages → Deploy from branch → `main` / `/ (root)`).
